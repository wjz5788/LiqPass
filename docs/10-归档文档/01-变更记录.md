## 技术架构演进

### 当前技术栈
- **前端**: React 18 + TypeScript + Vite
- **后端**: Node.js + Express + TypeScript
- **智能合约**: Solidity 0.8 + Hardhat
- **验证服务**: Python + FastAPI
- **数据库**: PostgreSQL + SQLite
