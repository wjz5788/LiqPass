## 在其他模块的安全复用
- 需要用户登录态（JWT）：
  - `const authService = new AuthService()`；`const requireAuth = createAuthMiddleware(authService)`
  - 路由：`router.get('/secure', requireAuth, handler)`（仅该路由启用，不影响其他）
- 需要后台 API Key：
  - `const requireApiKey = createApiKeyAuthMiddleware(dbManager)`
  - 路由：`router.post('/admin/task', requireApiKey, handler)`；如需权限：`createApiKeyAuthInstance(dbManager).middleware(['scope:a'])`
- 需同时支持 JWT 与 API Key：
  - `const enhanced = createEnhancedAuthMiddleware(authService, createApiKeyAuthInstance(dbManager))`
  - 路由：`router.post('/claims', enhanced.claimAuth(), handler)` 或自定义 `enhanced.middleware({ requireAuth:true, allowedMethods:['jwt','apiKey'] })`
- 需发起交易所验证：
  - 统一调用 US 后端代理路由：`POST /api/v1/verify/okx` 或 `POST /api/v1/verify/okx/standard`（`apps/us-backend/src/routes/okx-verify.ts:291-383`）
  - 或在服务内使用客户端封装：`apps/us-backend/src/services/jpVerifyClient.ts:44-56`
- FastAPI 内新增端点需鉴权调用：
  - 先校验密钥：`validate_api_credentials(...)`
  - 复用签名与调用：`generate_okx_signature(...)` + `call_okx_api(...)`

## 头部与环境配置
- JWT：`Authorization: Bearer <token>` 或 `x-session-token`
- API Key：`X-API-Key-Id` + `X-API-Key-Secret`
- JP：`ALLOWED_ORIGINS`、`OKX_BASE_URL`；US：`JWT_SECRET`
