## 字段对齐
- 你这页与 API 验证走的是同一个后端 `/api/v1/claims/verify`，输入都用同一个 `orderRef` 与 `claimId/orderId`，返回结构一致。
- 相比你现在 DEMO 的 `VerifyResult`，后端“理赔详情”多两个字段：
  - `payoutSuggest`（建议赔付金额）
  - `payoutEligibleAt`（到达待放款的时间，等同你现在的 `readyForPayoutAt`）
- 映射建议：
  - `readyForPayoutAt` ← `payoutEligibleAt`
  - 可选：在证据卡片增加一行“建议赔付金额”：显示 `payoutSuggest`。
